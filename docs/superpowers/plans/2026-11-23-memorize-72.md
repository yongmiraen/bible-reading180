# 성경암송 72구절 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 조원들이 사랑의교회 「성경암송 72구절」을 함께 연습·체크·복습하고, 조원 전체 현황을 보는 기능을 통독 앱에 추가한다.

**Architecture:** 정적 목록(`memorize-data.js`)과 순수 로직(`lib/memorize-logic.js`, node 테스트)을 분리하고, 화면은 `memorize.js`에서 기존 `render()` 라우터의 새 view `'memorize'`로 그린다. 외운 기록 원본은 `users/{uid}.memorized`에만 쓰고, 현재 조의 `members/{uid}.memorized` 사본은 `groups.js`의 트랜잭션 기반 맞춰 쓰기(reconcile)가 유지한다. Firestore 규칙은 에뮬레이터로 검증 후 사용자가 콘솔에 배포한다.

**Tech Stack:** vanilla JS(브라우저 전역, 빌드 없음), Firebase compat SDK 10.13.2, Firestore, node:test, Playwright 1.60(WebKit·Chromium·설치된 Chrome/Edge), Firestore 에뮬레이터 + `@firebase/rules-unit-testing`, Java(Temurin 21).

**Spec:** `docs/superpowers/specs/2026-11-23-memorize-72-design.md` — 실행자는 반드시 함께 읽는다.

## Global Constraints

- 빌드 도구·프레임워크 도입 금지. 브라우저 코드는 전역 스크립트(`<script src>`)로 로드.
- 기존 기능 제거·동작 변경 금지(스펙이 명시한 조 나가기·전체 초기화·참가 안내 변경 제외).
- `memorized`는 `pushSoloData`·`pushMapKeys`(전체 맵 저장 경로)로 **절대 쓰지 않는다**.
- 원본 값 형식: `{ [verseId]: 'YYYY-MM-DD' }`, verseId = 첫 절 키(예 `고후5:17`). 정규화 시 72개 등록 id + `^\d{4}-\d{2}-\d{2}$` 값만 남김.
- 규칙: `members.memorized` 선택 필드 `is map && size() <= 72`; `groups.memoStart` 조장만, 선택, `^\d{4}-\d{2}-\d{2}$`, 생성 payload엔 넣지 않음.
- 주차: 달력 날짜 차이, 시작일 당일부터 7일 = 1주차, 1~36주, 주 2구절(소주제 1개).
- `chunks`: 15어절 이하 `null`, 초과 45개는 사람 검토 필수, 이어 붙이면 원문과 공백·문장부호까지 동일.
- 복습 간격: 다음 날 → 3 → 7 → 14 → 이후 30일. 저장 localStorage 키 `memorize_review_v1_<uid>`.
- 버튼 최소 높이 48px(연습 카드), 글자 크기는 `verseFontSize()` 공유, 상태는 글자 + `aria-pressed`.
- 출처 문구 정확히: `출처: 사랑의교회 성경암송 72구절 (네비게이토)`.
- 보정: D묶음 고후 9:6,7 소주제 = `후히 드릴 것`.
- 배포 순서: 규칙 콘솔 배포(사용자) → 앱 push.

## Review Focus

1. **동기화로 다시 그려질 때 연습 중 가림·힌트·현재 부분이 유지되는가** — 다른 조원이 체크해 members 스냅샷이 와도 연습 화면이 처음 상태로 튀지 않아야 한다. → Task 7 테스트 `연습 상태가 동기화 재렌더 후 유지`.
2. **오프라인에서 체크 → 앱 재시작 → 재접속** — 원본·사본 모두 결국 맞아야 한다. → Task 4 에뮬레이터 테스트 `오프라인 체크 후 재접속 시 사본 복구`.
3. **큰 글씨(24px) + 320px 폭에서 갈 2:20 연습 카드** — 버튼이 겹치거나 화면 밖으로 나가지 않아야 한다. → Task 8 audit `memorize 24px 320px 가로넘침 0`.
4. **조장 아닌 조원이 시작일을 바꾸려 함** — UI에 버튼이 없고, 직접 호출해도 규칙이 거부. → Task 3 규칙 테스트 `일반 조원 memoStart 갱신 거부`.
5. **한국어 음성이 없는 기기(PC 사파리 엔진·일부 안드로이드)** — 듣기 버튼이 보이지 않고 오류도 없어야 한다. → Task 7 테스트 `ko 음성 없으면 듣기 버튼 없음`.
