# 탭/클릭으로 하이라이트·메모 툴바 열기 — 설계 문서

작성일: 2026-07-08

## 목표

지금은 절 텍스트를 **드래그 선택**해야 색상·메모 툴바가 뜬다. 이를 **절을 탭/클릭**하면 뜨게 바꿔서, 특히 모바일에서 쉽게 하이라이트·메모할 수 있게 한다.

## 결정 사항

- **트리거:** 절 텍스트 아무 곳이나 탭/클릭 → 그 절 기준 툴바가 **탭 지점 근처**에 뜸
- **동작 유지:** 색 선택 → 절 전체 하이라이트, 📝 → 그 절 메모 (기존과 동일)
- **닫기:** 다른 곳 탭 / 스크롤 → 닫힘
- **드래그 선택도 유지:** 기존 selectionchange 표시도 남김(데스크톱 호환)
- **데스크톱 힌트:** 절에 `cursor:pointer`

## 범위

`app.js`의 하이라이트 IIFE(`initHighlighter`)만 수정 + `index.html` CSS 1줄. 하이라이트/메모 데이터·저장·동기화·절 전체 단위·📝 뱃지는 변경 없음. "툴바를 여는 방법"만 변경.

## 변경 상세

### app.js — initHighlighter IIFE
1. **selectionchange 핸들러**: 접힌 선택일 때 `hideToolbar()` 호출을 제거(그냥 return). 비접힘 선택이면 기존대로 선택 rect에 툴바 표시. (닫기는 바깥 클릭/스크롤이 담당 → 단순 탭과 충돌 방지)
2. **click 핸들러 교체**: 툴바/메모뱃지 클릭이면 무시. 탭 지점의 절 요소를 찾고, 활성 선택이 없으면(단순 탭) 그 절을 `_targetRef`로 설정하고 **탭 좌표(clientX/clientY) 지점**에 툴바 표시. 절이 아니고 선택도 없으면 `hideToolbar()`.
3. scroll → hideToolbar (기존 유지)

### index.html
- `.verse, .verse-compare { cursor: pointer }` 추가

## 검증 포인트

1. 절 탭 → 탭 근처에 툴바 → 색 선택 시 절 전체 하이라이트
2. 절 탭 → 📝 → 메모 편집창
3. 바깥 탭/스크롤 시 툴바 닫힘
4. 드래그 선택으로도 여전히 툴바 뜸(데스크톱)
5. 📝 뱃지 탭은 메모 편집(툴바 아님) — 기존대로
6. 색상/✕ 버튼은 하이라이트만(📝는 메모)

## YAGNI

- 절 번호만 탭하는 방식(전체 탭으로 결정)
- 롱프레스/우클릭 메뉴 등
